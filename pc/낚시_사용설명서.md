# 끌림 매크로 v0.10 — PC 낚시

기존 어비스 화면 옆에 낚시 탭을 추가했습니다. F8 시작/일시정지, F9 즉시정지와 하단 실행 버튼은 두 탭에서 공통입니다. 실행 중 탭을 변경하면 일시정지합니다.

## 배포본 실행

설치 EXE 또는 포터블 ZIP에는 Python, Tesseract 실행 파일과 한국어 데이터가 포함됩니다. 별도 설치 없이 실행하세요. 포터블 ZIP은 전체를 압축 해제하고 `_internal` 폴더를 `Kkullim.exe` 옆에 유지하세요.

## 소스에서 실행 / 직접 빌드

1. Python 3.10 이상을 설치합니다. `pc` 폴더에서 `py -m pip install -r requirements.txt`를 실행합니다.
2. Tesseract OCR Windows 실행 파일을 설치합니다. 기본 경로 `C:\Program Files\Tesseract-OCR\tesseract.exe`를 자동으로 찾으며, 다른 위치라면 낚시 탭에서 지정할 수 있습니다. 한국어 모델은 `pc/tessdata/kor.traineddata`로 포함했습니다. Python 패키지만 설치해서는 Tesseract 실행 파일이 설치되지 않습니다.
   - Windows 배포 안내: https://github.com/UB-Mannheim/tesseract/wiki
   - 한국어 모델: https://github.com/tesseract-ocr/tessdata_fast (Apache 2.0, LICENSE 포함)
3. `py kkullim_pc.py`로 실행합니다. 게임이 관리자 권한이면 프로그램도 같은 권한 수준에서 실행해야 합니다.
4. EXE가 필요하면 `build_windows.bat`를 실행합니다. 결과는 `pc/dist/Kkullim.exe`입니다. Tesseract 실행 파일은 EXE에 포함되지 않으므로 PC에 별도 설치해야 합니다.

## 첫 설정: 영역 3개 지정

게임을 수동 낚시 모드로 준비합니다. 각 지정 버튼을 누르고 안내창을 닫은 뒤 3초 안에 게임 창을 앞으로 가져오세요. 캡처된 정지 화면에서 드래그해 영역을 선택하면 저장됩니다. Esc는 영역 지정 창만 닫습니다.

- **문구 영역:** 화면 아래 입질/결과 문구가 나오는 부분만 좁게 지정합니다. 채팅창·캐릭터 이름은 제외하고 `싱싱한 녀석을 낚았다` 같은 결과 문구도 들어오게 합니다.
- **게이지 영역:** 입질이 온 상태에서 머리 위 초록색 막대와 빈 검정 부분 전체를 선택합니다. 아이콘·캐릭터 이름·주변 풀은 제외합니다. 초록색 부분만 선택하면 게이지 비율을 잘못 판단합니다.
- **시작 버튼:** 낚시를 중단한 상태에서 오른쪽 아래 일반 낚싯대 아이콘을 지정합니다. 물고기가 걸린 낚기 버튼이나 네모 중단 버튼을 등록하지 마세요. Space 글자와 주변 화면은 되도록 제외합니다.

영역과 시작 버튼 이미지는 프로그램 옆 `fishing_settings.json`, `fishing_idle.png`에 저장됩니다. 게임 창 크기가 달라지면 다시 지정해야 합니다. 같은 크기여도 UI 배율이나 카메라 변경으로 위치가 달라지면 재지정하세요.

## 실행

처음에는 **인식만 확인**을 선택하고 F8을 누른 뒤 게임 창을 앞으로 가져옵니다. 이 모드에서는 키를 보내지 않습니다. 직접 낚시하면서 미리보기의 영역, 인식 문구, 게이지 및 제안 동작을 확인합니다. 제안된 낚기/취소 동작 뒤 사용자가 조작하지 않으면 결과 확인 시간이 초과되어 정지할 수 있습니다.

확인 후 F9로 정지하고 실제 실행을 선택해 다시 시작합니다. 실행 모드나 낚기 조건을 바꾸면 일시정지합니다.

| 문구 | 기본 동작 |
| --- | --- |
| 묵직한 느낌 | 게이지 반등 때 Space |
| 예감이 좋다 | 게이지 반등 때 Space |
| 찌가 흔들렸다 | 게이지 반등 때 Space |
| 입질이 왔다 | 게이지 반등 때 Space |
| 반응이 왔다 | 취소 후 다시 시작 |
| 뭔가 걸렸다 | 취소 후 다시 시작 |

상위 4개 문구의 체크를 해제하면 해당 문구도 취소 대상으로 바뀝니다. 하급 2개는 취소로 고정되어 있습니다. 문구 인식은 띄어쓰기·문장부호를 무시하며 연속 2회의 OCR 결과로 확인합니다. 인식되지 않은 문구에는 낚기/취소 입력을 보내지 않습니다.

**하급 취소 키 기본값은 Esc이며 실제 PC 게임에서 취소로 동작하는지 별도로 확인해야 합니다.** Esc가 메뉴를 열거나 다른 동작을 하면 그대로 사용하지 마세요. Space도 선택 가능하지만 PC에서 그것이 해당 상태의 취소로 동작한다고 확인된 경우에만 선택하세요. 자동 취소가 실제로 가능한 키는 업로드된 영상만으로 확정할 수 없었습니다. 입력 후 게이지 소실과 시작 버튼이 확인되지 않으면 재입력하지 않고 정지합니다.

## 입력 및 반복 판정

- 게이지는 약 50ms 주기로 확인하고 OCR은 별도 작업자로 실행합니다. 실제 주기는 캡처·OCR 성능에 따라 달라집니다.
- 첫 등장 시 게이지가 차오르는 애니메이션은 반등으로 취급하지 않습니다. 전체 길이의 15% 이상 감소한 뒤 저점보다 2.5% 이상 늘어나는 장면이 연속 2회 확인되면 Space를 한 번 보냅니다.
- 입력 후 결과를 기다리며 연타하지 않습니다. 결과 문구에서 낚았다는 내용이 확인되어야 성공 횟수가 올라갑니다. 취소는 게이지가 사라지고 시작 버튼이 확인되어야 집계됩니다.
- 시작 버튼 이미지가 연속 확인될 때만 다음 낚시를 시작합니다. 수동/자동 모드를 자동으로 전환하지 않습니다.
- 게임 창이 비활성화되면 입력을 멈추고 게이지 변화 기록을 버립니다. 창 크기 변경, 결과 확인 실패, 게이지 소실, 진행 시간 초과에도 정지합니다.
- 성공 횟수 `0`은 무제한입니다. 횟수와 진행 제한 시간은 시작 시 적용됩니다.
- 일시정지 중 사용자가 게임을 진행해 상태가 달라졌다면 게임 낚시를 중단하고 회차 초기화 후 다시 시작하세요.

## 검증 범위

샘플 2개의 게이지를 실제 영상 시간 기준으로 재생해 초기 등장 애니메이션에는 입력하지 않고 감소 후 반등에서 낚기 요청이 발생하는지 검증했습니다. 문구 판별, 입력 중복 방지, 결과 집계, 미확인 문구, 초점 상실 및 시간 초과 처리를 자동 테스트합니다.

현재 작업 환경은 Linux이므로 실제 Windows Tk 화면 실행, 게임 키 입력과 상급/최상급 낚시 성공은 검증하지 못했습니다. 상급/최상급은 동일한 문구 판별·게이지 로직을 사용하지만 해당 실전 샘플은 없습니다.

Windows UI 초기화 검사: `py kkullim_pc.py --selftest` (게임 입력 없음).
자동 테스트: `py -m pip install pytest` 후 `py -m pytest tests -q`.
