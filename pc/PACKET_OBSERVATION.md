# 투창 정답·성공 관찰 시험판 0.10.6

1번 방 투창 기믹의 화면과 패킷을 대조하는 관찰 도구입니다. 이번 기록에서 **내 캐릭터, 불 속성 투창, 정답 주술사 위치, 적중 후 성공 근거**를 연결했습니다. 게임 입력은 계속 차단합니다. 모비레이 실행 파일과 설정은 수정하지 않습니다.

이 배포는 확보된 PC v0.10 소스를 바탕으로 한 별도 실행 파일입니다. 로컬 v0.14.4/v0.14.5에 통합된 버전이라고 주장하지 않으며 기존 배포 파일을 덮어쓸 필요가 없습니다. Python·Tesseract·한국어 OCR 데이터를 단일 휴대용 EXE에 포함합니다.

## 이번 기록으로 확인한 결과

사용자가 제공한 46.8초 기록을 원본 PCAP과 같은 시각의 좌표 창 이미지로 재분석했습니다. 서버 7,720프레임, 클라이언트 95프레임, 위치 후보 갱신 422개를 읽었습니다. 170826 외에 실제 이동 중 사용된 170815·170830 위치 형식을 추가했습니다. 확인하지 못한 압축 메시지 2개는 미해석으로 남깁니다.

- 좌표 창의 X·Y와 패킷 궤적이 20회, 서로 다른 6개 위치에서 일치했습니다. 이 기록의 내 캐릭터를 구별하고 투창 대상이 나인지 대조했습니다. 개체 ID는 기록마다 다시 검증하며 하드코딩하지 않습니다.
- 불 속성 시전과 투척, 불 주술사 위치 `(10, 160)`을 연결했습니다. 주술사는 고정된 생성 구조와 해당 개체의 속성 행동이 함께 일치해야 인정합니다. 여섯 속성 주술사의 역할은 관측했으나 **현재 능동 투창 판별은 불 속성만 검증**했습니다.
- 기록 시작 약 26.25초에 불 시전, 32.25초에 투창 표식의 부착 해제·위치 고정 후보, 33.95초에 투척, 34.30초에 정답 주술사와 보스의 성공 반응을 관측했습니다. 주술사 반응만으로 성공 처리하지 않고 같은 보스의 그로기 또는 일치하는 보스 버프 해제를 함께 요구합니다.
- 화면에서도 적중 전에 정답 위치를 떠난 사례가 확인됩니다. 표식 위치 고정은 **이탈 후보**이며 자동 이동을 허용하는 검증된 신호가 아닙니다. 고정 대기 시간을 구현하지 않았습니다. 표식이 이름표와 겹치거나 별이 사라지는 것만으로 성공을 판단하지 않습니다.

원본 패킷·이름표·주소는 공개 저장소와 배포 검사 자료에 넣지 않았습니다. 공개 OCR 회귀 이미지는 좌표 숫자 영역만 남긴 익명 합성 캔버스이며 출처는 `tests/fixtures/COORDINATE_FIXTURES.md`에 기록했습니다.

## 사용

1. 모비레이가 동작하는 기존 PC에서 새 EXE를 별도로 실행합니다. 기존 Npcap을 사용합니다.
2. 1번 방 투창병 구간에 들어간 뒤 **패킷 기록** 탭에서 F8을 누릅니다. **기존 좌표 창도 함께 기록**, **이동 보정 자료 함께 기록**은 기본으로 켜져 있습니다.
3. 평소처럼 직접 이동하며 기믹을 수행합니다. 내 캐릭터 대조, 불 패턴과 목표 위치, 수행 상태를 관찰 화면에 표시합니다. 검증 근거가 부족하면 미확인으로 남깁니다.
4. F8 또는 F9로 정지하고 **패킷 ZIP 저장**을 누릅니다. 최대 60초 또는 패킷 12MiB에 도달하면 자동 정지합니다. 저장·첨부는 사용자가 직접 하며 자동 업로드는 없습니다.
5. **ZIP 재생**으로 과거 기록을 다시 분석하고 **분석 JSON 저장**으로 결과를 내보낼 수 있습니다. 과거 상태임을 표시하며 저장된 요약의 신원 주장을 그대로 신뢰하지 않습니다.

이번 버전은 수동 조작의 WASD·마우스 상태와 좌표를 같은 시각으로 기록하므로 키 이름을 채팅에 따로 적을 필요가 없습니다. 카메라 방향과 이동 대응 관계, 도착 오차, 안전한 이탈 조건은 이 자료로 다음에 검증합니다. 아직 보정값이나 자동 이동·공격·다음 방 전환을 연결하지 않았습니다.

## 기록과 판별 범위

- 게임 PID의 실제 TCP 16000번 연결만 확인하고 기존 Npcap 수신 API로 기록합니다. 무차별 수신은 끄며 패킷 송신·재전송·주입은 하지 않습니다. 연결 변경·종료 시 정지합니다. UDP는 지원하지 않습니다.
- TCP 중복·재정렬·공백·충돌을 처리하고 확인한 서버/클라이언트 경계만 분석합니다. 알려진 시작/종료 배치로 동기화한 뒤 배치 밖 메시지도 읽습니다. 해석 실패·오래된 상태·연결 재동기화는 관련 판별 근거를 무효화합니다.
- 좌표 창 증거는 가리지 않은 기존 창만 약 1초 간격으로 캡처합니다. 최근 30장·장당 2MiB·총 8MiB로 제한하며 전체 화면 캡처로 대체하지 않습니다. 이름표가 포함될 수 있습니다. 원본 크기·해시·캡처 전후 시각과 실제 프레임 ID를 보존합니다.
- 내 캐릭터 판별은 같은 수신 출처·연결·세대에서 반복된 화면 좌표 일치와 충분한 위치 변화를 요구합니다. 부호·소수점을 임의 보정하지 않으며 유효 OCR 결과가 충돌하면 거부합니다. 이미지/시각/출처 검증 실패나 분석 시간 초과 시 부분 결과로 신원을 확정하지 않습니다. 진단용 좌표 일치 오차는 게임 도착 허용 오차가 아닙니다.
- 이동 보정 기록은 **해당 게임 PID가 전면일 때만** W/A/S/D·좌우 마우스 버튼·커서 위치를 수동적으로 읽습니다. 다른 키·채팅·다른 앱 입력을 기록하지 않습니다. 90초·2,000행·256KiB 상한을 두며 패킷 기록과 함께 정지합니다. 키/마우스 입력을 발생시키지 않습니다.
- 실행 폴더 `packet_logs/실행ID` 아래 저장합니다. ZIP에는 현재 실행의 정해진 메타데이터·장치별 PCAP·해석 요약과 선택한 화면/이동 증거만 포함합니다. 게임 통신 원문에 IP·포트와 계정/개체 정보가 포함될 수 있습니다.

## 남은 검증

WASD와 좌표 방향의 대응, 카메라 회전 영향, 이동량과 지연, 목표 부근 도착 오차는 아직 검증되지 않았습니다. 한 기록의 조기 이탈 후보를 모든 속성·상황에 일반화하지 않습니다. 로딩·사망과 자동 이동 중의 정지 조건, 다른 능동 속성과 이후 빙고 기믹도 입력 연결 전에 검증해야 합니다. 관찰 모드에서는 게임 입력 자체가 차단되어 있습니다.

## 근거와 검사

[모비레이 공식 홈페이지](https://mobilay.kr/)에서 Npcap과 미니맵 기능을 확인했지만 조사한 공개 페이지에서 실시간 좌표 출력 API 규격은 확인하지 못했습니다. 이것이 해당 기능이 없다는 증명은 아닙니다. [제작자 기능 설명](https://gall.dcinside.com/mgallery/board/view/?id=enban&no=1186490)은 물길 안내와 테로사 추천 계산을 설명합니다. 완성된 정답 별이 패킷에서 전달된다고 가정하지 않습니다. 수신 코드는 [Npcap 공식 API 문서](https://npcap.com/guide/wpcap/pcap.html)를 기준으로 작성했으며 공개된 과거 파서 코드는 가져오지 않았습니다.

단위 검사는 재조립·범위/시간 제한·신원 격리·불 상태 전이·증거 검증·ZIP 내보내기를 다룹니다. Windows 배포 검사는 EXE 하나만 빈 폴더에 복사해 UI와 내장 OCR/Brotli, 합성 패킷·좌표 대조·불 성공 전이·기록 내보내기를 확인합니다. 패키징 검사와 실제 게임 이동 검증은 별개이며, 이번 버전의 새 실시간 관찰·수동 이동 자료 수집은 사용자 PC에서 확인해야 합니다.
